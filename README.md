# The Rookie: Badge of Honor

An ethical puzzle game based on the TV show "The Rookie" - a standalone desktop application for macOS.

## About the Game

Step into the boots of Officer Alex Chen, a rookie LAPD officer facing real moral dilemmas. Every choice shapes your character, and every puzzle tests your judgment. The badge is just metal - YOU decide what it means.

Inspired by the ABC Television Series "The Rookie" created by Alexi Hawley.

## Features

- **5 Unique Scenarios**: Face ethical dilemmas inspired by real police situations
- **Decision-Based Gameplay**: Your choices affect your integrity score and story outcomes
- **Puzzle Elements**: Solve evidence analysis, logic, and procedural puzzles
- **Multiple Endings**: Your final rank depends on the choices you make
- **Immersive Storytelling**: Experience the challenges of being a rookie cop

## Scenarios Include

1. **First Day on the Beat** - Balancing law enforcement with compassion
2. **Behind Closed Doors** - Navigating domestic violence situations
3. **The Blue Wall** - Testing integrity when facing corruption
4. **The Breaking Point** - Personal stakes vs. professional duty
5. **The Measure of a Badge** - The ultimate test of judgment

## Requirements

- macOS (10.14 Mojave or later recommended)
- Python 3.8 or later (pre-installed on most Macs)

## Installation & Running

### Quick Start (Recommended)

1. Download or clone this repository
2. Double-click `run_game.command` to launch the game
3. If prompted, right-click and select "Open" to allow the app to run

### Command Line

```bash
# Navigate to the game directory
cd deehelloworld

# Run the game
python3 rookie_puzzle_game.py
```

### First-time macOS Setup

If you get a security warning:
1. Right-click on `run_game.command`
2. Select "Open" from the context menu
3. Click "Open" in the dialog that appears

## Gameplay Guide

### Integrity Score
- Start with 50 points (out of 100)
- Ethical choices increase your score
- Compromising choices decrease your score
- Your final score determines your ending

### Final Rankings
- **80-100**: Exemplary Officer
- **60-79**: Good Officer
- **40-59**: Struggling Officer
- **0-39**: Compromised Officer

### Tips
- Read each scenario carefully before making decisions
- Pay attention to the puzzle hints - they inform your choices
- Consider the consequences, not just the immediate outcome
- There are no perfect answers, only your judgment
